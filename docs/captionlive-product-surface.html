Interface Details

รายละเอียดและข้อกำหนดของแต่ละหน้าจอ

CONTROL PLANE

Control Room (ส่วนควบคุมระบบ)

ศูนย์กลางการบริหารจัดการห้องสื่อสารเรียลไทม์ (LiveKit Room) สั่งการวงจรชีวิตของเอเจนต์ถอดเสียง และออกโทเคนกำกับสิทธิ์ดิจิทัลแก่ทุกส่วนงาน

  • เส้นทาง URL (Route) /#admin หรือ /
  • โปรโตคอลและความปลอดภัย HTTP REST API (Go Backend Fiber Framework) + CONTROL_API_KEY
  • กลุ่มผู้ใช้งานหลัก Administrator / System Operator

Key System Components

⚡ Room Provisioning Manager

สร้าง เปิด หรือปิดห้องสื่อสารเรียลไทม์ ตรวจสอบการเชื่อมต่อของ WebRTC Room

🤖 Provider Agent Supervisor

สวิตช์เปิด/ปิดวงจรชีวิตเอเจนต์ถอดเสียง Google STT, Gemini Live, Azure, GPT Realtime

🔑 Signed Token Gateway

ออกโทเคนกำกับสิทธิ์ลงนามดิจิทัล (JWT/Token) คัดลอกส่งให้ Audio Source, Desk และ Viewer

PUBLISHER PLANE

Audio Source (สถานีสตรีมเสียงสด)

ขอสิทธิ์และสตรีมสัญญาณเสียงสดจากไมโครโฟนหรือ Chrome Tab ตรงเข้าสู่ LiveKit Media Room ผ่าน WebRTC ด้วย Opus Codec โดยไม่ผ่าน WebSocket

  • เส้นทาง URL (Route) /#stream?room=<room_name>
  • โปรโตคอลและรูปแบบสื่อ WebRTC Peer Connection (48kHz Opus Audio Track) ตรงสู่ LiveKit Media Server
  • กลุ่มผู้ใช้งานหลัก Publisher / Audio Streamer

Key System Components

🎙️ Audio Device Selector

สลับเลือกอุปกรณ์ไมโครโฟน หรือเปิดโหมดจับสัญญาณเสียงจาก Chrome Tab

📊 Peak Level Visualizer

มิเตอร์แสดงระดับความดังเสียงเรียลไทม์ ป้องกันปัญหาสัญญาณเสียงเบาเกินไปหรือแตกพร่า

📡 WebRTC Direct Publisher

เผยแพร่ Opus audio track ตรงเข้าสู่ LiveKit Room เพื่อให้เอเจนต์ดักจับ PCM

EDITORIAL PLANE

Caption Desk (ส่วนตรวจทานและอนุมัติแคปชัน)

ส่วนงานบรรณาธิการ รับข้อความ Draft และ Final เรียลไทม์ผ่าน LiveKit Data Channel พร้อมโหมดแก้ไขคำผิดและกด Enter อนุมัติการเผยแพร่แคปชัน

  • เส้นทาง URL (Route) /#caption-desk?room=<room>&provider=<provider>
  • โปรโตคอลสื่อสาร LiveKit Data Packets: caption.operator (รับ Draft) → caption.publish (ส่งอนุมัติ)
  • กลุ่มผู้ใช้งานหลัก Editor / Verbatim Reviewer

Key System Components

👁️ Draft Stream Preview

แสดงข้อความร่างแบบอ่านอย่างเดียวเรียลไทม์ เพื่อให้บรรณาธิการอ่านเตรียมตัวล่วงหน้า

⌨️ Keyboard Fast Editor

ข้อความ Final เข้าสู่กล่องบรรณาธิการทันที แก้ไขคำผิดด้วย `Enter` (ส่งอนุมัติ) และ `Shift+Enter` (ขึ้นบรรทัดใหม่)

🚀 LiveKit Data Publish

เมื่อกด Enter ระบบจะส่งข้อความเข้า LiveKit Data Channel กระจายสู่หน้าจอผู้ชมทั่วโลกทันที

CONSUMER PLANE

Transcript (หน้าจอรับชมถอดเสียงสด)

หน้าจอแสดงผลบทถอดเสียงสดแบบอ่านอย่างเดียว สำหรับผู้รับชมทั่วไป รับข้อมูลจาก LiveKit Data Channel แสดงผลข้อความ Draft และ Final พร้อมคำแปลขนาน

  • เส้นทาง URL (Route) /#viewer?room=<room_name>&autoconnect=1
  • โปรโตคอลรับข้อมูล LiveKit Reliable Data Channel Packet Subscription (Read-Only)
  • กลุ่มผู้ใช้งานหลัก Viewer / Audience / Reader

Key System Components

📑 Dual-View Engine

เลือกสลับมุมมองระหว่าง Lines View (ถอดความพร้อมคำแปลสองภาษาขนานกัน) และ Text View

🔍 Provider Stream Filter

เลือกกรองดูเฉพาะเอเจนต์ Provider ที่ต้องการ (เช่น Google, Gemini, GPT) หรือดูรวมทั้งหมด

💾 Sanitized Text Exporter

ส่งออกไฟล์ข้อความบทถอดเสียงเสร็จสมบูรณ์ (`.txt`) โดยกรองแยกข้อความร่างออกโดยอัตโนมัติ

ดูรายละเอียดเส้นทางสัญญาณ PCM, WebRTC และ WebSocket ได้ที่ System Flow Diagram
